# 项目架构与开发计划

本项目自身的架构设计与实施路线（外部资料见 [参考资料/](./参考资料/README.md)）。

## 整体架构

采用「离线生成 + 前端阅读」分离的结构：生成端按需运行产出素材，阅读端只做播放与交互。

```
生成端（离线，按需运行）
├── 故事文本生成（LLM）
├── 角色参考图生成
├── 每页插画生成（注入角色参考图，如 SenseNova U1 或 FLUX 2 Pro）
├── 中英双语 TTS 合成（离线生成音频文件，如 Edge TTS / Chatterbox / Fish Speech）
└── 输出：图片 + 音频 + 文本 + 热区配置

阅读端（前端）
├── 绘本图片 + SVG 热区层
├── 音频播放管理器（状态机 + 播放队列）
├── 语言切换（切换音频资源 + 文本）
└── 页面导航
```

---

## 开发优先级

1. **先跑通前端**：用静态绘本（图片、音频、热区配置写死）验证 SVG 热区点击、音频播放、语言切换、自动/手动翻页。
2. **再接入生成端**：先用 **Edge TTS**（零成本）和 **SenseNova U1**（角色一致性最优）跑通生成流程。
3. **最后优化体验**：按需求更换更高质量的 TTS（Chatterbox 或 Fish Speech），并增加情感控制。
