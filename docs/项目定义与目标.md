# 项目定义与最终目标

## 项目定义

这是一个**基于 Web 的 AI 驱动、多模态、中英双语交互式电子绘本生成与阅读系统**，属于 **AIGC 内容生成、数字出版、教育科技与多模态人机交互**的交叉领域。

更精确地说，它不是单一的「AI 画图工具」或「有声书播放器」，而是一个**端到端系统**：

- **生成端**：将故事意图转化为结构化的多模态绘本资产；
- **阅读端**：通过 Web 阅读器将这些资产以可交互、可切换语言、可自动/手动播放的形式呈现给用户。

## 一句话专业描述

> 这是一个面向儿童教育、语言启蒙和个性化绘本创作场景的 Web 端 AI 多模态电子绘本平台，通过 LLM、图像生成和 TTS 构建中英双语绘本内容，并在交互式阅读器中以热区点击、语言切换、自动/手动配音播放的方式完成沉浸式阅读。

## 技术本质

将非结构化的故事意图，转化为结构化的多模态绘本资产（图、文、音、热区），再通过 Web 阅读器进行可交互消费。

---

## 核心功能

### 1. AI 绘本内容生成

根据用户输入的主题、角色或教育目标，自动生成中英双语故事文本、分页脚本和插画。重点解决角色跨页一致性、画风统一和图文语义对齐。

### 2. 中英双语配音合成

通过 TTS 技术将中英文文本合成为音频，支持情感化朗读，并输出两套平行音频资源。用户可在阅读时全局切换中文或英文。

### 3. 交互式 Web 阅读器

打开网页即可阅读电子绘本，支持：

- **中英文切换**；
- **自动播放模式**：按页顺序连续播放配音，音频结束自动翻页或播放下一条；
- **手动播放模式**：用户自行控制播放、暂停、翻页；
- **音频状态管理**：避免多段音频重叠，保证播放队列与页面同步。

### 4. 图片热区交互

在绘本插画上设置热区，热区与音频、文本或动作绑定。点击热区即可播放对应音频，实现「点哪里、读哪里」的增强阅读体验。热区需支持响应式布局，适配不同屏幕尺寸。

### 5. 双语资源与播放状态管理

系统维护中英两套文本、音频和热区配置。切换语言时，当前页面、播放位置和交互状态应正确衔接，而不是简单刷新页面。

### 6. 绘本资产输出与消费

- **生成端输出**：图片、双语文本、双语音频、热区配置；
- **阅读端消费**：形成一本可在浏览器中直接阅读、点击、收听、切换语言的电子绘本。
