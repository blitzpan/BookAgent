# BookAgent 本地部署运行指南（全部模块）

本仓库是一个 monorepo，**可独立运行的部分共 3 个**（外加 2 组可选测试）。本文逐个给出启动命令，全部命令在 Windows PowerShell + Node v20.18.0 上实测通过。

## 0. 有哪些部分要启动

| # | 模块 | 目录 | 作用 | 端口 | 依赖谁 |
| --- | --- | --- | --- | --- | --- |
| 1 | **backend**（API / 生成服务） | `backend/` | Fastify + SQLite(sql.js)；文本改写、生图、审批状态、页图托管 | `3000` | 无（最底层，必须先起） |
| 2 | **reader**（阅读端 / front） | `reader/` | React 只读阅读端：书架 + 阅读器（双语、字号、跨页） | `5173` | backend |
| 3 | **frontend**（管理壳） | `frontend/` | React 管理端：建故事 / 改写 / 生图配置 / 补画 / 选默认图 / 发布；`/api`、`/assets` 代理到 3000 | `5174` | backend |

三个模块端口互不冲突（3000 / 5173 / 5174），可同时启动。

可选（不是常驻服务，按需执行）：

| 项目 | 命令 | 说明 |
| --- | --- | --- |
| 后端单元测试 | `cd backend; npm test` | vitest + mock provider，不需要起服务 |
| 端到端测试 | 根目录 `npm run test:e2e` | Playwright 自动起 backend(3000) + reader(5173)，跑移动端/Pad 用例 |

## 1. 前置条件

- **Node.js ≥ 20.12**（后端用内置 `process.loadEnvFile` 读配置；实测 20.18.0 / npm 10.8.2）
- 无需安装数据库、无原生编译：后端用 `sql.js`（纯 WASM，数据落盘为文件）
- `frontend` 的页面样式已改为**构建期 Tailwind**（PostCSS + `tailwind.config.js`），离线不影响样式，产物经裁剪（CSS ~30KB gzip 6KB），可正式上线

```powershell
node -v
npm -v
```

## 3. 模块一：backend（必须先起）

### 3.1 配置环境变量

后端启动时**自动加载**配置文件（`backend/src/env.ts`，用 Node 内置 `process.loadEnvFile`，无需 dotenv 依赖），
不再需要 `--env-file`，直接 `npm run dev` 即可。

加载顺序（**先加载的优先级高**，后加载的不会覆盖已存在的值；shell 里已导出的环境变量优先级最高）：

| 顺序 | 文件 |
| --- | --- |
| 1 | `backend/.env.local` |
| 2 | 仓库根 `.env.local`（当前用法） |
| 3 | `backend/.env`（照 `backend/.env.example` 复制） |
| 4 | 仓库根 `.env` |

四个位置都已被 `.gitignore` 忽略，不会进版本库。想临时覆盖某一项，在 shell 里导出即可（如 `MOCK_AI=0 npm run dev`）。

### 3.2 变量说明

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MOCK_AI` | `0` | **省钱总开关**：`1` / `true` / `yes` / `on` 时整个后端走本地 mock，零真实调用、零费用；开启后下面的 `*_PROVIDER` 与所有 API Key 全部被忽略 |
| `PORT` | `3000` | 监听端口 |
| `BOOKAGENT_DATA_DIR` | `backend/data` | 数据目录：内含 `bookagent.db` 与 `assets/`（页图） |
| `CORS_ORIGIN` | `*` | 放行来源；生产改成前端域名 |
| `TEXT_PROVIDER` / `IMAGE_PROVIDER` / `VISION_PROVIDER` | `gemini` | 三角色分派：`gemini` / `bailian`(=`qwen`) / `ark` / `seedream`(仅图像) / `mock` |
| `GEMINI_API_KEY` | — | 默认全角色 |
| `BAILIAN_API_KEY` + `BAILIAN_BASE_URL` | — | 阿里百炼（千问 + 万相） |
| `ARK_API_KEY` + `ARK_BASE_URL` | — | 火山方舟（豆包 + Seedream，单 Key 覆盖三角色） |
| `BAILIAN_TEXT_MODEL_NAME` / `BAILIAN_VISION_MODEL_NAME` / `BAILIAN_IMAGE_MODEL_NAME` | `qwen-plus` / `qwen-vl-plus` / `wan2.7-image` | 百炼模型名覆盖 |
| `ARK_TEXT_MODEL_NAME` / `ARK_VISION_MODEL_NAME` / `ARK_IMAGE_MODEL_NAME` | `doubao-seed-1.8` / `doubao-1.5-vision-pro` / `seedream-5.0-pro` | 火山方舟模型名覆盖 |
| `GEMINI_TEXT_MODEL` / `GEMINI_VISION_MODEL` / `GEMINI_IMAGE_MODEL` | `gemini-3-pro-preview` / `gemini-3-pro-preview` / `gemini-3-pro-image-preview` | Gemini 模型名覆盖 |
| `SEEDREAM_API_KEY` + `SEEDREAM_BASE_URL` + `SEEDREAM_MODEL_NAME` | — | 火山 Seedream（仅图像，可共用 `ARK_API_KEY`） |
| `TTS_MOCK` | 非空即静音占位 | 配音走 `edge-tts-universal`；置位时写出静音 MP3、零网络（离线联调/测试用） |
| `TTS_RETRY` | `3` | 单段合成失败重试次数 |
| `TTS_RETRY_BASE_MS` | `800` | 重试指数退避基数（ms） |
| `TTS_INTERVAL_MS` | `300` | 段间限速间隔（ms），避免触发微软限流 |
| `TTS_SYNTH_TIMEOUT_MS` | `40000` | 单段合成超时（ms） |
| `VOICE_FETCH_TIMEOUT_MS` | `30000` | 「设置 → 更新音色」拉取微软音色池超时（ms） |

⚠️ 国内 provider **必须填完整 `*_BASE_URL`**：源码默认值是 `/bailian-api`、`/ark-api` 这种**浏览器 Vite 代理用的相对路径**，Node 端直连会因无法解析 URL 而失败：

```bash
BAILIAN_BASE_URL=https://dashscope.aliyuncs.com
ARK_BASE_URL=https://ark.cn-beijing.volcesengine.com
```

## 5. 模块三：reader（阅读端 / front）

- 用途：只读阅读，书架 + 阅读器（中/英/双语、字号三档、≥768px 可切跨页）。

## 8. 首次启动 reader 书架空？造一本已发布的书

reader 只展示 `status === '审批通过的作品'`。两种方式：

### 方式 A：用管理壳 UI（推荐）

http://localhost:5174 → 新建故事（填原文 + 页数）→ 改写 → 生图（等 **task** 变 `completed`，版本 run 变 `completed` / `partial_failed`）→ 发布。刷新 http://localhost:5173 即可看到。

### 方式 B：命令行跑完整链路（mock provider 下已实测）

```powershell
# 建故事（PowerShell 传 JSON body 最稳）
$s = Invoke-RestMethod -Method Post -ContentType 'application/json' `
     -Body '{"original_text":"一只小猫的一天。","target_page_count":4,"user_title":"本地测试"}' `
     http://localhost:3000/api/stories
$id = $s.id

# 改写（安全 → 润色 → 分页），同步返回
curl.exe -s -X POST http://localhost:3000/api/stories/$id/rewrite
# => {"storyId":1,"mode":"good_polish","feedback":"mock: 直接采用原文","pageCount":4,...}

# 整书生图（异步）：返回版本 runId + 执行 taskId
curl.exe -s -X POST http://localhost:3000/api/stories/$id/generate      # => {"taskId":1,"runId":1}

# 进度与结果看 task（completed / failed），不要轮询 run
curl.exe -s http://localhost:3000/api/tasks/1

# 版本产物（每页默认图、候选图、角色锚图、序列校验）看 run
curl.exe -s http://localhost:3000/api/runs/1

# 发布：生图完成待审批 → 审批通过的作品
curl.exe -s -X POST http://localhost:3000/api/stories/$id/publish
# => {"ok":true,"status":"审批通过的作品"}

# reader 书架应能看到
curl.exe -s -G http://localhost:3000/api/stories --data-urlencode "status=审批通过的作品"
```

### 方式 C：完全不依赖后端

`reader/.env` 设 `VITE_USE_MOCK=true`，重启 reader，书架出现 3 本示例书。

## 10. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `EADDRINUSE :3000` / `:5173` / `:5174` | 对应模块已在跑（或上次残留）：`Get-Process node \| Stop-Process -Force` |
| 改了 `.env.local` 没生效 | 配置只在启动时加载一次，改完要**重启** backend；确认文件放在 `backend/.env.local` 或仓库根 `.env.local` |
| 配了 `MOCK_AI=1` 却仍在调用真实模型 | shell 里已导出的环境变量优先级最高，会盖住文件里的值；`$env:MOCK_AI=0` 之类先清掉再重启 |
| 生图报 `Failed to parse URL` / 百炼 401 | `BAILIAN_BASE_URL` / `ARK_BASE_URL` 没设成完整 https 地址（默认 `/bailian-api` 是浏览器代理路径） |
| 管理壳能看到书，reader 书架空的 | reader 只显示 `审批通过的作品`；在管理壳点「发布」 |
| 管理壳有图、reader 图裂 | reader 直连 `VITE_API_BASE`；确认该地址就是 backend，且 `BOOKAGENT_DATA_DIR` 下 `assets/` 有文件 |
| PowerShell 调 POST 返回 `415 Unsupported Media Type` | `Invoke-RestMethod -Method Post` 默认带 JSON Content-Type 但 body 为空；无 body 接口改用 `curl.exe -s -X POST <url>`，或补 `-Body '{}'` |
| curl 传 JSON body 报 `Body is not valid JSON` | PowerShell 引号转义把 body 破坏了；用 `Invoke-RestMethod -Body`，或写文件后 `--data-binary @file.json` |
| 管理壳样式全乱 | 检查 `frontend/src/index.css` 与 `tailwind.config.js` 是否接入，并重跑 `npm run build`（已非 CDN 方案） |
| 控制台中文变 `???` | `chcp 65001`；不影响接口与数据 |
| 想重置本地数据 | 删 `backend/data`（含 `bookagent.db`、`assets/`），或给 backend 另设 `BOOKAGENT_DATA_DIR` |
| 浏览器报 CORS | backend 默认 `CORS_ORIGIN=*`；生产部署设为前端域名 |

## 11. 生产构建（可选）

```powershell
# frontend 管理壳 → frontend/dist
cd frontend ; npm run build ; npm run preview

# reader 阅读端 → reader/dist（打包前把 VITE_API_BASE 指向真实后端地址，运行时改不了）
cd reader ; npm run build ; npm run preview

# backend（会自动读取 .env.local / .env）
cd backend ; npm start
```

部署时把两个 `dist/` 静态托管，后端 `CORS_ORIGIN` 收紧为对应域名；页图仍由后端 `/assets/*` 提供（或改由 Nginx 直接读 `BOOKAGENT_DATA_DIR/assets`）。
