## 1. 设计语言草案（Design Tokens）

### 1.1 统一令牌层（两端共用一套变量，各自套主题）
在两端各建 `src/styles/tokens.css`（CSS 变量），Tailwind 主题 `extend` 引用同名变量，实现「一套令牌、两主题」。

```
间距 base=4px:  --sp-1=4 --sp-2=8 --sp-3=12 --sp-4=16 --sp-6=24 --sp-8=32 --sp-12=48
圆角:            --r-sm=8 --r-md=12 --r-lg=16 --r-xl=24   （克制，不再全 2xl）
字体阶梯:        --fs-12/14/16/20/24/32/40  (比例≈1.25)
阴影:            --sh-1/2 低透明度、暖色调（非纯黑投影）
动效:            --ease-out=cubic-bezier(.2,.7,.2,1); --dur-1=150ms --dur-2=250ms --dur-3=350ms
```

### 1.2 管理后台主题「绘本工作室 · 暖纸感」（去紫靛）
| 令牌 | 值 | 说明 |
|---|---|---|
| `--bg` | `#FAF6EF` 暖纸白 | 整体背景，非纯白 |
| `--surface` | `#FFFFFF` | 卡片 |
| `--surface-2` | `#F1E9DB` 沙色 | 分区/次级块 |
| `--ink` | `#332E27` 墨棕 | 主文字 |
| `--muted` | `#8A8175` | 次要文字 |
| `--primary` | `#C8643C` 赤陶（terracotta） | **唯一主色**，温暖、手作感，与紫靛科技感决裂 |
| `--primary-ink` | `#FFFFFF` | 主色上的字 |
| `--gold` | `#E0A458` 暖金 | 次级强调（评分/徽标点缀） |
| 语义色 | 中性灰（新建）/ 蓝（进行中）/ 琥珀（待处理）/ 绿（完成·通过）/ 红（失败） | 小圆点+文字，降饱和，不再 8 色高亮 pill |

> 标题不再用渐变文字，改为实色字 + 一个手绘感小标记（如一笔波浪/小书本 SVG），品牌气质来自排版而非滤镜。

### 1.3 阅读端主题「绘本夜 · 暖墨」（保留沉浸、做精致化）
| 令牌 | 值 | 说明 |
|---|---|---|
| `--bg` | `#15131F` 暖近黑墨 | 舞台背景（图留边时也用同色调而非纯黑） |
| `--surface` | `#211E2E` 面板 | 工具栏/导航 |
| `--text` | `#F5EFE6` 暖纸白 | 文案 |
| `--muted` | `#9C93A6` | 次要 |
| `--accent` | `#F2C879` 精炼暖金（原 `#ffd166` 提纯度） | 播放/翻页/热区高亮 |
| 沉浸规则 | 插画满版（`cover` 或同色调去黑边 `contain`）；文案以底部 `linear-gradient(transparent→--bg)` 半透明浮层压图 | 真正「图上读书」 |

> 备选：若目标受众偏 3-6 岁低龄，可加一套「日间绘本」浅色主题（米白底+插画原色），作为可切换项；本期先不做，留接口。

## 2. 信息架构（IA）

### 2.1 管理后台：引入真实路由（修 D31，支持深链/预览）
新增 `react-router-dom`（reader 已用，前端未装）。三态改为路由：
```
/                        故事列表 + 新建（StoryList）
/story/:id              单书工作台（StoryDetail：概览/分页脚本/配置/生图/配音/热区入口/发布）
/story/:id/hotspots     热区编辑器（HotspotSettings，独立路由，便于「去阅读端预览」深链返回）
```
收益：刷新不丢位置、可分享某本书/热区页、与「阅读端一键预览」形成闭环。

### 2.2 阅读端：结构保留，补分享出口
```
/                    书架（真实封面）
/book/:id            阅读器（手机单页 / Pad 跨页）
/book/:id/share      （阶段三可选）分享卡/海报页
```
现有 `/` 与 `/book/:id` 已用 `react-router-dom`，无需重构。

## 4. 样式基础设施决断（必须先定，否则后续是空中楼阁）

**问题**：frontend 用 Tailwind CDN（不可上生产）；reader 写了 Tailwind 类却不加载（全失效）。
**提案（推荐）**：**两端统一接入构建期 Tailwind**（Vite 插件 / PostCSS），以 CSS 变量令牌驱动 theme，`darkMode: 'class'`。
- frontend：移除 `index.html:7` 的 CDN `<script>`，改为 `npm i -D tailwindcss postcss autoprefixer` + `tailwind.config.js`（content 扫描 src，theme.extend 引用 §1 令牌）。现有 90% 类名可直接保留，仅 `dark:` 需配 `.dark` 类或沿用媒体策略。
- reader：安装同样 Tailwind 构建链；把 `global.css` 的色值迁移为 §1.3 令牌变量，`PageView.tsx` 里**已写好的 Tailwind 类（bg-violet-600 等）改为令牌色工具类或补 token 映射**——这样「之前白写的类」反而成为可用资产，而非推倒重来。
- 两 app 共享同一份 `tokens.css`（可放 `design/` 或各自复制一份，保持变量名一致）。

> 备选：reader 不接 Tailwind，改为把 `PageView.tsx` 的失效类全部改写为 `global.css` 里的具名类。成本更低但两端仍两套体系，不推荐。
